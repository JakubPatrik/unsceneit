## `seo/d-google.md` (Google SEO for the Store Page)

1. **SERP Mechanics for CWS Pages:**
* Google displays CWS listings for long-tail phrases like `youtube gore filter extension` or `spider blocker chrome extension`.
* Google pulls the **SERP Title** directly from the Extension Name (`<title>`) and the **Meta Description** from the first 150–160 characters of the Store Description.
* *Critical Action:* The first two sentences of our store description must contain our core value proposition and primary keywords to maximize Google SERP click-through rate.


2. **Off-Page Backlink Strategy (No Outreach Required):**
* High-value indexed directories: Product Hunt, AlternativeTo, Chrome Extension lists, and organic Reddit threads.
* Internal web linking: `[https://unscene.it](https://unscene.it)` should link directly to the CWS store URL using optimized anchor text (e.g., *"Install unscene.it Chrome Extension"*).
